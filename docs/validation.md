# 验证范围

## v0.2.0：三类模块，2026-11-10

本机 macOS、Python 3.14，运行脚本只依赖标准库。12项脚本测试覆盖原有初始化保护、三个模块独立安装、重复安装、自定义内容保护、命令行模块选择和发布包逐文件完整性。项目检查器另检查分类引用、技能资源独立性、Markdown相对链接及24位人物分组。

三个技能均可单独安装；完整项目包与三个单技能包由同一份目录生成，并在独立临时目录解压核对。不包含使用者个人资料或本地生产路径。GitHub CI配置在Linux、Python 3.10和3.14运行脚本与项目检查。

未验证：真实用户长期效果、不同工具自动触发、Windows真机、账号申诉结果与任何“防封”效果。测试不替代这些验证；名人方法卡保留各自原始来源和核验状态，迁移不将部分核验升级为全文核验。

