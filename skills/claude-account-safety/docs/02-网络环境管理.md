# 02 · 网络与登录

先核对[Claude服务状态](https://status.claude.com/)。记录打不开的页面、错误原文、时间和使用产品，再按[官方支持](https://support.claude.com/en/articles/9015913-how-to-get-support)排查。

在允许服务的地区，可以比较普通网络连通性，检查浏览器版本、扩展或企业网络策略；一次改变一个条件，保留结果。不要索取或复制登录Cookie，不为规避服务地区限制而设计代理或设备伪装。

无法从网络类型、ASN、设备数或出差推断账号评分。没有依据规定“仅1—2台设备”“网络占一半权重”或“必须固定IP”。怀疑凭证泄露时优先保护邮箱与身份提供方，并使用产品当前可用的会话管理功能；不要编造密码或二步验证入口。

核对日期：2026-11-10。
