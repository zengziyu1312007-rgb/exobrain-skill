# 04 · 政策入口

规则以[Usage Policy](https://www.anthropic.com/legal/aup)、[个人服务条款](https://www.anthropic.com/legal/consumer-terms)及相应产品的当前说明为准。本页只提供阅读入口，不重写一套永久有效的禁止清单。

遇到拒答、内容过滤或账号警告时，先看具体提示与当前政策；一次拒答不等于账号已被封。不能通过“使用主题多样化”“声明学习用途”来保证不会触发限制。

任务涉及他人数据时确认权属与用途，尽量减少不必要个人信息。医疗、法律、财务等专业结论需合适的人核验，AI输出不能替代专业责任。

认为被误判时走[官方警告与申诉说明](https://support.claude.com/en/articles/8241253-safeguards-warnings-and-appeals)，不承诺有违规记录就一定不能申诉或一定永久封禁。核对日期：2026-11-10。
