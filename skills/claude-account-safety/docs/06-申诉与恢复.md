# 06 · 申诉与恢复

账号明确被停用、且认为处理有误时，按[Safeguards warnings and appeals](https://support.claude.com/en/articles/8241253-safeguards-warnings-and-appeals)登录受限账号，使用页面提供的申诉表单。入口需要登录；实际可见内容以账号页面为准。

登录、账单和产品问题按[How to get support](https://support.claude.com/en/articles/9015913-how-to-get-support)选择当前支持入口。申诉无需先等待固定观察期；处理时间与结果由官方决定。

## 材料草稿

```text
我的账号于[日期和时区]在[产品]出现[错误原文]。
我希望核实的是[受限原因／恢复访问／账单问题]。
已完成的检查：[只列实际做过的事及结果]。
相关请求或工单编号：[如有，按官方表单填写]。
请告知是否需要补充材料及可行的后续步骤。
```

账号邮箱等定位资料仅填入真实官方渠道，不放公开Issue。身份证明按官方确有要求时提交，不主动发送密码、验证码、Cookie、API key或完整支付资料。助手可以起草材料，发送需用户相应授权。

账户最终无法恢复时，查看官方提供的数据导出、账单处理与删除选项；受限账号可用功能可能不同。不建议通过更换身份、设备画像或新账号绕过封禁。核对日期：2026-11-10。
