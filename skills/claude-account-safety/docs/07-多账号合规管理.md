# 07 · 工作、个人与团队账号

个人与工作资料按权属、组织制度与实际产品权限分开。团队协作用产品支持的席位、组织或工作区，不共享个人登录Cookie、验证码或API密钥。

各环境的密钥与授权按实际需要分配，凭证保存在受支持的密钥管理或本地环境中，不写入外脑笔记、公开仓库或聊天示例。离职与人员变更由组织管理员按流程收回权限。

是否允许同一人持有不同用途账号、支付方式要求和席位规则，以[当前条款](https://www.anthropic.com/legal/consumer-terms)与[官方支持](https://support.claude.com/en/articles/9015913-how-to-get-support)为准。不规定必须用不同身份、设备或IP，也不提供批量注册或通过多个账号绕过限额的做法。
