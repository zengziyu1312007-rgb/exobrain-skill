# 03 · 使用与限额

聊天订阅、Claude Code和API的额度与计费不应混为一谈。以账号当前显示的用量、重置时间和官方说明为准，不把额度耗尽自动判成封禁，也不编各档“安全会话数”。

API按[官方错误说明](https://platform.claude.com/docs/en/api/errors)识别问题：401先查鉴权；429先查用量与速率；529属于过载错误，不能据此推断账号被封。记录请求ID和脱敏错误，不记录API key。

需要重试时遵守官方返回的等待提示，使用有上限的退避；鉴权或参数错误先修正原因，避免无限重复调用。具体重试次数取决于任务时限与接口建议，不是账号“防封阈值”。

用量异常增加时检查应用、权限与密钥暴露；确认泄露后由有权限的用户撤销受影响密钥并更新依赖。没有官方依据要求所有API必须固定服务器IP或长期保留某个余量才安全。
