# 05 · 异常自查

先记录产品、错误原文、发生时间、请求ID（若有）与最近可核实的变化。截图脱敏；不要求用户交出凭证。

| 现象 | 下一项检查 |
|---|---|
| 页面打不开或多人同时异常 | [服务状态](https://status.claude.com/)与网络连通性 |
| 登录失效 | 邮箱或身份提供方能否登录、当前页面验证提示 |
| 聊天显示额度限制 | 当前产品的用量与重置提示 |
| API 401 / 429 / 529 | [错误说明](https://platform.claude.com/docs/en/api/errors)：鉴权 / 限流 / 过载 |
| 扣款或订阅异常 | 对应产品账单、付款渠道与银行提示 |
| 明确显示账号受限或停用 | [官方申诉](06-申诉与恢复.md) |
| 未授权使用或用量异常 | 保护邮箱与登录会话，核查密钥、授权和账单 |

以上是检查方向，不是已确认原因。无法判定时联系[官方支持](https://support.claude.com/en/articles/9015913-how-to-get-support)，不以“先等24—48小时”为硬性前置条件。
